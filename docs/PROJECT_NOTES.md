# 프로젝트 및 정리 범위

## 저장소 범위

이 저장소는 졸업 팀 프로젝트에서 작성한 백엔드 코드를 포트폴리오 검토용으로 재구성한 것입니다.

- 포함: Flask 애플리케이션 API, Django 날씨 API, Firebase 연동, 외부 AI 서버 연동 코드
- 미포함: Android 프론트엔드, AI 모델 학습·추론 서버의 내부 구현
- 전체 팀 결과물은 루트 README의 원본 저장소 링크에서 확인할 수 있습니다.

## 원본에서 제외한 항목

- Python 가상환경(`venv`, `.venv`)
- `__pycache__`, `.pyc` 등 생성 파일
- Firebase 서비스 계정 JSON, `.env`, Google 서비스 설정 파일
- 로컬 SQLite 파일과 테스트용 업로드 이미지
- 중복된 의존성 목록
- 런타임에서 사용하지 않는 초기 로그인 실험 코드와 일회성 데이터 수정 스크립트
- 현재 구현에서 사용하지 않는 초기 Oracle 스키마 초안

## 유지한 항목

- 기존 API 경로와 요청·응답 처리
- JWT 및 Firebase 인증 흐름
- 옷장 CRUD와 이미지 분석 결과 정규화
- 추천 서버 호출, 재시도, 타임아웃, 결과 및 피드백 저장
- 커뮤니티 게시글·댓글·소셜 기능
- OpenWeather 조회와 날짜별 Firestore 저장 규칙

## 보안 정리

원본 개발 파일에 포함돼 있던 모든 인증 정보와 고정 서버 주소는 제거하거나 환경변수로 전환했습니다. 이 저장소에는 실제 키를 커밋하지 않습니다.
